About CraveKart Project

Second-Year Computer Engineering Academic Project

Project Overview

CraveKart is a modern, responsive single-page food ordering web application built as part of the Web Technology curriculum for Second-Year Computer Engineering students. It demonstrates core front-end software concepts including DOM manipulation, client-side state management, client-side routing, and responsive web design.

Technologies Used

HTML5 CSS3 (Flexbox & Grid) JavaScript (ES6+) LocalStorage API FontAwesome Icons
